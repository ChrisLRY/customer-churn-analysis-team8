# Clustering Analysis

K-Means customer segmentation for the telecom churn dataset (k = 4).

## Contents
- `02_Clustering_Analysis.ipynb` / `.html`: full analysis report
- `Optimal_Clusters/`: elbow method and silhouette plots, plus the numbers behind them
- `Model/`: trained K-Means model (`kmeans_model.joblib`)
- `Cluster_Visualisation/`: cluster plots with business labels
- `cluster_assignments.csv`: cluster label for every customer (`row_id`)

Input data is read from `../Data_Preparation/`.
